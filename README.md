# 全民训练大模型 · 微信小游戏体验工程

这是微信原生Canvas 2D小游戏工程，不依赖浏览器DOM、不需要安装Cocos或npm运行依赖。已填写AppID `wx0f4818a31ccc7104`。

## 导入（Mac）

1. 下载工程ZIP，双击解压。
2. 微信开发者工具左侧选「小游戏」，右上点「导入」。
3. 目录选择解压后的文件夹：该层必须能直接看到 `project.config.json`、`game.js`、`game.json`。
4. 项目名称可保留「全民训练大模型」，AppID保留已填值，导入并编译。
5. 模拟器可滑动，也可依次点击两个相邻图标。编译正常后点「预览」，用管理员/开发者微信扫码真机体验。

本地文件无远程资源请求，无需填写AppSecret或上传密钥。不要开启云开发，不要为此项目关闭域名校验。遇到提示先截图，不要把密钥发聊天。

## 内容

- 无限三消、四连行列芯片、五连万能核心与交叉爆破。
- 两张等层级算力/数据卡，自动获取A100/H100、模型自动训练和模拟MaaS服务Token。
- 说明页、背景音乐、匹配音效和连击人声；首次触摸激活，设置可分别关闭。
- 通过微信本地存储保存，网页与微信进度独立。重置需确认。
