# 全民训练大模型

手机竖屏 H5 三消养成游戏：点选三个相同的原始数据完成清洗，立即获得金币、能量与训练数据，再升级显卡、训练模型。训练与消除可以同时进行，完成的模型自动产生虚拟 MaaS 收益。

## 运行

Node.js 18+，零第三方运行依赖。

```sh
cd /workspace/game
npm run dev
```

默认监听 `0.0.0.0:3000`，可用 `PORT` 覆盖。入口为 `index.html`；`assets.html` 展示已接入的原创素材；`research.html` 提供商业游戏参考、官方截图来源和设计取舍。

## 玩法

- 首页直接游玩，点三份相同数据自动消除，整理台最多七格。
- 每组消除立即获得能量、金币和一份对应训练数据，连续消除有加成。
- 免费撤回未结算的一步；每关三次洗牌会将未消除数据放回，并重建可解排列。
- 前两关只有三类数据，后续逐步加入图像、语音和推理。生成器按合法移除顺序成组三消数据，保证存在解。
- 点击绿色成长按钮，资源满足后喂入数据训练。GPU 不消耗，能量和数据消耗。
- 训练完成自动加入模型小队、开启虚拟 MaaS 收益。点顶部金币气泡收取。
- 模型成长：豆豆 0.1B → 灵灵 1B → 喵喵 3B → 星云 7B。试玩版本之后可继续消除，未实现的蒸馏和 MoE 只作为后续方向。
- 知识题是可选彩蛋；设置可切换专业/大众题库，操作音与原创背景音乐分别控制。

## 技术与素材

Canvas 2D 绘制三消棋盘；透明 DOM 命中按钮提供触控和键盘支持。HTML/CSS 构建手机布局、养成面板、粒子与弹窗。Web Audio 合成原创音效与循环音乐，无外部音频版权依赖。`content.js` 独立配置训练成长、硬件与两类题库。

原创 AI 生成机房背景、角色/奖励图集和六类数据道具已接入；参考作品的官方截图仅出现在调研页面，不用于本游戏资产。真实硬件型号规格附官方来源，价格、倍率、模型能力和收入为虚构数值。

## 存档与边界

浏览器 `localStorage` 键为 `everyone-trains-models-v2`。旧版 `model-tycoon-v1` 单独保留；重置需要确认且不清理旧版。存档不可用时仍可游玩，但进度不能跨会话保存。离线最多计算两小时收益，待领取上限 5,000。

无账号、无支付、无广告、无服务端个人数据收集，也没有真实模型训练或真实 benchmark 分数。服务端只提供明确列出的静态资源，拒绝其他文件与写入方法。部署静态页面时不需要 Node 服务。
