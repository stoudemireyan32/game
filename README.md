# 全民训练大模型 · 经典模型连连看

点两张相同的大模型图标，用最多两次拐弯的空路径连起来，赚取金币、能量和训练数据，升级显卡并训练自己的模型。完成的模型自动产生虚拟 MaaS 收益；连连看与训练同时进行。

## 运行

Node.js 20+，无第三方运行依赖。Playwright 仅用于开发测试，不进入网页运行包。

```sh
npm run dev
```

启动时生成完整 `play.html`，监听 `0.0.0.0:3000`。可用 `PORT` 覆盖。默认首页直接提供打包版，源码拆分的开发入口为 `index.html`。

```sh
npm run build
npm test
npm run check
```

静态托管只需 `play.html`；`progress.html` 是独立的北京时间制作日志。打包版已内置 CSS、全部 SVG 图标、规则引擎和原创 Web Audio 音乐，启动不请求额外图片、字体或脚本。第三方预览服务自身的加载器请求不计入游戏资源数。

## 核心玩法

- 相同品牌两张配对，路径只沿水平/垂直方向，不穿过其他牌，最多两次拐弯；允许绕棋盘边缘。
- 非法配对不扣资源。提示、重排免费。没有可连牌时自动重排，剩余品牌数量和已获得资源不变。
- 初始棋盘通过合法移除顺序成对分配类型保证可完成。第一关六种品牌，后续八种；短屏首次进入使用较少行数，改变窗口时保留当前棋盘。
- 每对立即发放能量和金币；每连接三对，额外提炼一份下一阶段需要的训练数据。
- 模型：豆豆 0.1B → 灵灵 1B → 喵喵 3B → 星云 7B。训练消耗能量与数据，显卡永久保留。
- 训练完成不强制弹窗打断连连看；模型自动上线并持续产生虚拟收益。点顶部金币气泡收取。
- 背景音乐是原创八小节循环，包含主旋律、贝斯、鼓点和镲片，另有轻快模式；金币音效和背景乐分别开关，首次操作后激活。

## 实现与资源

HTML/CSS Grid 直接绘制并命中同一张牌，SVG 只画连接反馈线；不再使用 Canvas 与透明命中层。棋盘布局不依赖初始化时的像素尺寸或 DPR。连接线使用操作时的实际 DOM 几何位置。

`engine.js` 为可独立测试的纯 JavaScript 规则模块；`content.js` 配置模型、显卡和品牌 SVG；`music.js` 实时合成原创音乐及音效；`scripts/build.mjs` 生成单文件。没有 React/Three.js 或包安装步骤。

品牌图标来自 Lobe Icons 1.102.0，npm 包下载经 SHA-512 校验；MIT 许可和来源见 `vendor/`，游戏内也附完整说明。名称和商标归各品牌所有，不代表合作。图标只是配对主题，不表示真实调用品牌模型或获取其训练数据。

## 日志与存档

```sh
node scripts/log-progress.mjs '实际完成的事项与验证结果'
```

命令以实际系统时间记录 UTC 与 Asia/Shanghai，北京时间日志见 `docs/progress-log.md`，机器记录见 `docs/progress.jsonl`。每次构建把日志快照加入游戏设置/玩法说明和独立日志页；不是持续在线状态监控。

本版存档键 `everyone-trains-models-link-v3`，与旧版独立，重置需要确认且不清理其他键。禁止存档时仍可游玩，损坏存档回退新游戏。离线收益最多计两小时，待领取封顶 5,000。

验收记录见 `docs/qa-v3.md`。手机检查为云端 Chromium 触控与尺寸模拟，尚未代表真实 iOS/微信设备测试。

## 可重复的浏览器回归

首次准备开发测试可运行 `npm ci`。云环境已提供 Chromium；其他环境可用 Playwright 安装 Chromium，或用 `CHROMIUM_PATH` 指定现有浏览器。先启动 `npm run dev`，再运行 `npm run test:browser`；用 `PLAY_URL` 可指定不同服务地址。浏览器脚本从全新存档实际点按到 1B 成长，不靠预置资源替代主流程。

当前云端已有早期任务服务占用默认端口时，可用 `PORT=3005 npm run dev` 启动；验证时相应使用 `PLAY_URL=http://127.0.0.1:3005/play.html npm run test:browser`。不要终止无法确认归属的监听进程。
