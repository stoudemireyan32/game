# 微信原生Canvas体验工程验收

## 工程范围

`wechat/`为独立微信小游戏工程，含已填AppID的project.config.json、game.js/game.json、纯规则、原生Canvas渲染、微信触摸、InnerAudioContext、本地存档、生命周期、PNG和本地MP3。没有HTML/web-view，也不需要Cocos。

此前提出Cocos作为后续方案；本次为减少用户安装和导入步骤，首版实际选择原生Canvas 2D，核心规则继续复用。H5版本保持独立，不清理其存档。

## 已执行

- 4项原生控制器回归：合法/非法交换、从零获A100/H100、自动训练接续、Token收益、存档、重置中断在途交换、损坏/禁用存档。
- Chromium微信API模拟层，真实CDP触摸，在390×844、320×568、375×667走通三消、获卡、自动训练、手册返回、退出保存与重载；没有页面异常。
- 已看过Canvas截图，修复PNG显卡被裁切、说明页误命中隐藏按钮。适配胶囊区与底部安全区，绘制与命中使用同一逻辑坐标及DPR变换。
- 稳定原生require入口，不使用浏览器window/document/localStorage/WebAudio。存档通过wx存储接口，音频使用本地MP3。

## 必须继续验证的边界

没有云端微信开发者工具或真实手机，不能声称微信官方编译/真机通过。接下来用户导入后首次编译，检查对应AppID权限、稳定基础库与机型兼容；手机预览检查音频/后台/安全区、触摸与存档。包体限额按开发者工具实际体检为准，不根据旧文档数字下结论。
