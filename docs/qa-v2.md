# 《全民训练大模型》v0.2 验收记录

2026-11-07，云环境 Chromium 156 / Playwright。记录实际执行结果，不等于所有浏览器、设备与网络都零故障，也不将自动化测试等同于真实用户长期留存验证。

## 已执行

- 全新存档的手机流程：打开即棋盘；正常点击三消后金币、能量、同类训练数据立即增加；未消除选取可撤回；刷新恢复棋盘、整理台和资源；通关奖励只支付一次；进入第二关有上下层遮挡。
- 用正常消除所得资源训练首个 0.1B 模型；训练中仍能点选数据；完成自动开启 MaaS 收益；收取收益、购买 A100、金币不足时阻止扣款。
- 独立的高阶段资源测试存档验证 1B / 3B / 7B 模型及 A100 / H100 / H200 门槛。未将这些预置资源描述成自然玩家进度。
- 训练数据购买及库存扣减；模型四阶段全部解锁；无须手动“上线”或切换后台列表。
- 通过合法点击构造 7 格满槽，免费撤回恢复；洗牌将未消除数据放回，清空整理台，重建可解布局。
- 独立 DFS 求解器检查 1～8 关共 24 个随机棋盘，全部能在 7 格整理台规则内完成；每类初始道具数量均为 3 的倍数。这是抽样测试，生成器同时通过合法移除顺序成组分配数据保证存在解。
- 离线收益上限与重复刷新不重复支付；重置需要确认，取消不清空；只清空 v2，保留旧版存档；浏览器禁止 localStorage 时仍可操作。
- 375×667、390×844、430×932、320×568、桌面 1440×1000 检查布局；手机竖屏无横向或纵向页面滚动；极小屏高阶棋盘在棋盘内部滚动，保证道具命中区至少 44px；横屏允许手机容器纵向滚动。
- 游戏服务只开放静态文件白名单，非公开文件返回 404，POST 返回 405；应用没有账号、支付、广告 SDK 或个人信息上报。
- 图集、场景、素材页图片均完成加载；Canvas 显示与 DOM 命中按钮一致。
- JavaScript 三个文件语法检查通过。

- 触控模拟实际 tap、Web Audio 解锁与音乐独立停止；知识题超时和答错均不发奖励；损坏存档自动恢复。
- 首次公网验收发现通关事件冒泡与延迟弹窗重复，已修复并以快速通关、立即下一关、继续训练和收币作回归验证。

- 公网素材页往返检查发现：第三方预览器不会重写运行时生成的链接，可能打开原始 HTML。已为动态手册链接补充同站预览路由，正常静态站仍使用相对链接。

## 人工观察与取舍

- 查看了新手与第二关在 390×844、375×667 和桌面的实际截图；主画面是彩色道具棋盘、整理槽和模型成长区，已移除侧栏和数据后台布局。
- 第一关只提供三类道具，降低入门失败可能；第二关引入遮挡，后续逐步增加类别。撤回、洗牌不收费、没有广告门槛。
- 对操作加入道具飞入、三消音阶、奖励粒子、连击浮字、通关反馈、模型诞生和单独可关的原创循环音乐。
- 初版 A100 门槛调整为 140 游戏金币，让完成首关和首次模型成长后可较快升级。
