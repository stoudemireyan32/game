# 网页小游戏改版调研 · 2026-11-07

## 方法和边界
实际检查了下列作品的 App Store 发行方玩法说明与官方截图，并查看 Idle Miner Tycoon 官方网站。未宣称已安装试玩这些商业游戏，也不将商店宣传截图当作实际操作录像。选择的是与本作相关的成熟经营/养成作品，不声称它们是当前全网热度排名。截图仅用于调研对照，绝不作为本游戏设备或角色素材。

## 观察与采用

| 作品 / 原始资料 | 观察 | 对本作的决策 |
|---|---|---|
| [Cooking Fever](https://apps.apple.com/us/app/id714796093) | 官方真实玩法截图中，顾客需求在上、食物与制作设备在下；同屏形成明确的点按操作闭环。设备升级、菜品解锁提供中期目标。 | 采用同屏直接操作与即时奖励；按用户后续要求以三消替代派单，不用读列表/跳页面。 |
| [Cooking Craze](https://apps.apple.com/us/app/id1029094059) | 说明强调点击烹饪、顾客满意度、快速服务奖励和厨房升级。 | 为连续交付加入连击、满意度条和金币飞入 HUD；避免强迫玩家答专业题才有收入。 |
| [Cooking Diary](https://apps.apple.com/us/app/id1214763610) | 订单图标、组合奖励、角色与装修成长并存。 | 单次操作有弹跳、声音和明确奖励，经营成长需要可见角色变化。 |
| [Idle Miner Tycoon](https://www.idleminertycoon.com/) / [商店](https://apps.apple.com/us/app/id1116645064) | 设备/人员/运输在场景中构成生产链，自动化和扩建是长期成长。 | GPU 是场景中的可点击设备；模型开始持续产出后，收益通过场景气泡收取。 |
| [Egg, Inc.](https://apps.apple.com/us/app/id993492744) | 说明直接强调用彩色 3D 场景替代菜单；孵化、扩建、研究支撑增量经营。 | 电脑也保持竖屏玩法，升级与孵化反馈不能藏在表格；不采用本作尚未验证的转生数值。 |
| [Cats & Soup](https://apps.apple.com/us/app/id1581431235) | 官方截图有完整场景、多个角色生产点；说明包括喂养、装扮、离线收入、音效与音乐。 | 模型具象为成长中的小机器人，训练是喂数据与孵化；保留柔和背景音乐与可独立关闭的操作音。 |
| [动物餐厅](https://apps.apple.com/us/app/id1460564684) | 店铺环境、顾客、设施、猫员工与收集故事构成温暖经营主题。 | 做“AI 小铺”而非企业控制台；图鉴和解锁提供角色目标，场景承担玩法。 |
| [Neko Atsume 2](https://apps.apple.com/us/app/id6499131935) | 操作说明只有放置食物/玩具与等待来访两步，收集记录是目标。 | 首页只保留一个主行动，图鉴显示已解锁与下一阶段，降低学习负担。 |

## 最终玩法（按用户后续反馈修订）

用户明确希望主操作低门槛、反复消除获得即时奖励，正式名称定为《全民训练大模型》。因此采用“三份相同原始数据点选入槽 → 三消清洗成一份训练数据，并即时发放金币与能量 → 购买 GPU / 补充数据 → 喂数据训练 → 模型角色诞生并自动产生虚拟 MaaS 收入 → 下一档模型与消除关卡解锁”。厨房订单只作为操作反馈的参考，不再作为主玩法。

打开首页直接显示可点击棋盘，不需要先接单或进菜单。整理台 7 格，免费撤回与洗牌；新棋盘及洗牌按合法移除顺序分配成组三消数据，至少存在一个解。前两关只用 3 种数据，后续逐渐增加至 6 类。训练独立计时，可以边消除边训练；专业知识题为可选彩蛋，题库与数值独立配置。

## 美术与音效制作约束

- 竖屏 H5，桌面居中模拟手机，不伸展成后台面板。
- 原创柔和 3D 玩具机房：薄荷绿、紫色、暖金色；统一光照和透视。
- 主场景、可交互角色/道具、HUD 分层；不能把按钮和中文烘焙进大图。
- Sprite：模型幼体与进阶体、GPU、数据、金币、能量；用独立 CSS 状态/粒子/动画表现操作。
- 明确反馈：点击缩放、完成弹跳、连击浮字、奖励飞行、训练孵化、设备升级。
- 原创 Web Audio 轻循环与点按/交付/升级旋律，可关闭；浏览器首次操作后播放。
- 不复制参考游戏的角色、界面、音乐或截图作为游戏资产。

## 发布前必须验证

390×844、375×667、手机横屏/桌面；首页无后台布局、主操作可见；从零存档完成三消→奖励→数据/GPU购买→训练→收益→下一阶段；错误操作可恢复；音效开关；刷新存档；长时间离线收益上限；知识题计时；所有素材成功加载；公网预览使用浏览器导航请求验证无额外确认页。

## v0.3 最终改版：经典连连看

用户进一步明确改为两张模型品牌图标配对，而不是三份数据入槽。参考 [Shisen-Sho 经典规则](https://en.wikipedia.org/wiki/Shisen-Sho)：水平/垂直空路径、不穿其他牌、最多两个拐点，可绕外边界。

新版采用同一 DOM 牌面完成绘制与点击，SVG 只呈现已经判定合法的连接线。模型图标来自经完整性校验的 Lobe Icons 矢量包并内联；不再依赖大型图片图集。音乐改为原创八小节旋律、贝斯与鼓组，提供两个风格和独立开关。具体测试边界见 qa-v3.md。
