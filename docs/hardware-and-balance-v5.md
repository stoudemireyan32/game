## 游戏规则

- 去掉金币、能量、显卡碎片和购买；没有关卡/步数收费/倒计时，保留无限三消和免费提示/重排。
- 普通3枚消除：26×3=78游戏算力进度，32×3=96 MB 数据。
- 四连：1.5倍并生成行列芯片；五连：2倍并生成万能核心；发动特殊芯片1.5倍；连锁每波再加25%，最多加100%。同波只按更高的组合加成，不把同一枚重复计数。
- 首张A100需要312进度，约4次普通三消。下一张H100需再780，约10次；后续每张多312，形成无限集群。资源溢出保留，进度满自动发卡，不花费累计资源。多张跨阈值可逐张展示。
- 显卡解锁有带型号/显存/实际峰值的约2秒亮相动画、光束、彩纸、人声；动画不用点击确认、不截获触摸。
- 数据只保留单一MB计数，自动缩放GB/TB，顶部显示下一模型的数据目标。采用1024进制显示约定，不声称字节与Token固定换算。
- 显卡数与数据满足条件就自动训练，训练完成自动上线虚拟MaaS；产出用已服务Token显示，不加回金币系统。数据和卡均不扣除。0.1B→1B→3B→7B→14B→32B→70B→128B MoE。

TFLOPS是运算速率，不是可累加工作量。本版按用户希望把TFLOPS映射为游戏进度；主界面称“累计游戏算力”，设置说明真实物理单位与游戏进度的区别。门槛为游戏平衡设定，不能当作实际训练需求或科学的单位换算。
