## 本轮实际发现并修复

- 单文件构建时使用字符串替换，可能把 JavaScript 中 `$$` 误解释成 `$`，导致脚本不能解析。已使用函数式原样替换，并为编译后整包增加回归测试。
- 连接 SVG 的高度改为由实际网格高度计算，避免把 SVG 自身滚动高度再次累加造成漂移。
- 图像和点击命中改为同一 DOM 元素，取消分离的 Canvas/透明层；全部品牌图标内联，移除大图集加载依赖。

## 公网验证及证书边界

候选版实测首次出现可操作牌面 1,051ms，共三个启动请求：预览外壳 1,269 字节、加载器 4,664 字节、游戏单文件 86,367 字节。游戏无额外素材请求。触控连接、改变窗口、训练时继续玩、自动收益、刷新存档、游戏内日志与独立日志往返均通过，无脚本错误。该时间是本执行环境的观测值，不保证其他网络相同。

测试 Chromium 的旧共享 NSS 库尚未信任当前环境代理证书；修正该共享信任被自动审批拒绝，未绕过。公网资源由现有系统 CA 校验的 curl 获取真实内容和响应头，再转交 Chromium 执行与交互；保留 Content-Type、CORS 和 nosniff 信息，不关闭 TLS 校验，也不使用忽略证书错误的浏览器选项。因此这证明公布资源和浏览器功能，不冒充普通用户直连网络、真实手机或真实 iOS 的全覆盖测试。

独立日志页缺少显式 head 导致预览器未插入 base、返回地址错误，已补全 head/body 并新增构建回归检查，公网往返复测通过。
